# TrafficGuard AI

Smarter Roads. Safer Journeys.

This repository contains a full-stack scaffold for TrafficGuard AI — an AI-powered Traffic Violation Detection and Vehicle Monitoring System. It includes a React + TypeScript frontend and a Node.js + Express backend with mock APIs and data to simulate AI-detected violations.

Quick start (development):

1. Backend

```bash
cd backend
npm install
npm run dev
```

2. Frontend

```bash
cd frontend
npm install
npm run dev
```

This scaffold provides core pages, mock endpoints, and a clear structure so you can later integrate real AI/ML services (YOLO, OpenCV, OCR) and a real MongoDB instance.
